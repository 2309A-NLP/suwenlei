# RAG问答系统部署文档

## 1. 项目概述

本项目是基于PDF文档的智能问答系统，使用RAG（检索增强生成）技术，以武汉兴图新科电子股份有限公司招股意向书为知识源。

### 1.1 系统架构

- **前端**：index.html（HTML + JavaScript）
- **后端**：FastAPI（app.py）
- **向量库**：Milvus（可选）
- **LLM**：DeepSeek API

### 1.2 核心功能

- PDF文档解析与索引
- 自然语言问答
- RAG与纯LLM对比
- 语音输入（Chrome）
- 评测系统

## 2. 环境要求

### 2.1 系统要求

- Python 3.8+
- pip

## 3. 部署步骤

### 3.1 获取代码

```bash
git clone <repository_url>
cd RAG工单1
```

### 3.2 创建虚拟环境

```bash
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# 或
venv\Scripts\activate  # Windows
```

### 3.3 安装依赖

```bash
pip install -r requirements.txt
```

或手动安装：

```bash
pip install fastapi uvicorn pydantic requests pymupdf pymilvus python-multipart
```

### 3.4 配置环境变量

创建 `.env` 文件：

```env
DEEPSEEK_API_KEY=your_api_key_here
DEEPSEEK_BASE_URL=https://api.deepseek.com
RAG_BACKEND=auto
```

或直接设置环境变量：

```bash
export DEEPSEEK_API_KEY='your_api_key_here'
export DEEPSEEK_BASE_URL='https://api.deepseek.com'
export RAG_BACKEND='auto'
```

### 3.5 准备PDF文件

将招股说明书PDF文件放置在项目根目录：

```
RAG工单1/
├── app.py
├── index.html
├── 招股说明书1.pdf  # 放置PDF文件
└── ...
```

### 3.6 启动服务

```bash
python app.py
```

启动成功后会显示：

```
========================================================
  RAG 问答系统 — 后端服务
  PDF: 招股说明书1.pdf
  后端模式: auto
  Query Understanding: 已启用
========================================================
访问地址: http://localhost:8888
```

### 3.7 访问系统

打开浏览器访问：http://localhost:8888

## 4. 配置说明

### 4.1 环境变量

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| DEEPSEEK_API_KEY | DeepSeek API密钥 | 无（必填） |
| DEEPSEEK_BASE_URL | API基础URL | https://api.deepseek.com |
| RAG_BACKEND | RAG后端类型 | auto |

### 4.2 RAG后端类型

- `auto`：自动选择（推荐）
- `milvus`：使用Milvus向量库
- `sklearn`：使用sklearn TF-IDF

### 4.3 端口配置

默认端口为8888，如需修改可编辑 `app.py` 中的端口设置。

## 5. 功能使用

### 5.1 基本问答

1. 在输入框输入问题
2. 点击发送按钮或按Enter
3. 系统返回基于PDF的回答

### 5.2 语音输入

- 需要Chrome浏览器
- 点击麦克风图标开始录音
- 再次点击停止录音

### 5.3 文件上传

- 支持上传多个PDF文件
- 上传后自动解析并添加到知识库
- 支持中英文PDF

### 5.4 对比模式

- 同时展示RAG回答和纯LLM回答
- 方便对比分析

## 6. 评测系统

### 6.1 访问评测

```bash
curl http://localhost:8888/api/evaluate
```

### 6.2 评测问题

系统内置10个标注评测问题，覆盖：
- 实体类问题（公司名称、地址等）
- 数值类问题（金额、比例等）
- 列举类问题（产品、客户等）

## 7. 常见问题

### 7.1 启动失败

**问题**：`ModuleNotFoundError: No module named 'fastapi'`

**解决**：安装依赖
```bash
pip install fastapi uvicorn pydantic requests pymupdf
```

### 7.2 PDF加载失败

**问题**：`PDF文件不存在`

**解决**：检查PDF文件路径是否正确

### 7.3 API调用失败

**问题**：`DEEPSEEK_API_KEY未设置`

**解决**：设置环境变量
```bash
export DEEPSEEK_API_KEY='your_api_key'
```

### 7.4 端口被占用

**问题**：`Address already in use`

**解决**：修改端口或停止占用进程
```bash
lsof -i :8888
kill <PID>
```

- Milvus模式性能更优
- sklearn模式无需额外服务

### 9.3 API调用

- 建议配置API密钥
- 可调整超时时间
