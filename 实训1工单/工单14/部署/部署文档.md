# RAGFlow 部署文档

## 一、环境要求

### 1.1 硬件配置

| 组件 | 最低配置 | 推荐配置 |
|-----|---------|---------|
| CPU | 8核 | 16核+ |
| 内存 | 16GB | 32GB+ |
| 磁盘 | 100GB SSD | 500GB SSD |
| GPU | 可选 | RTX 3060 12GB+ |

### 1.2 软件环境

- **操作系统**：Ubuntu 20.04+ / WSL2
- **Docker**：24.0+
- **Docker Compose**：2.20+
- **Python**：3.10+

## 二、快速部署

### 2.1 克隆RAGFlow项目

```bash
cd /mnt/e/桌面
git clone https://github.com/infiniflow/ragflow.git
cd ragflow/docker
```

### 2.2 配置环境变量

```bash
# 编辑 .env 文件
vi .env

# 关键配置
RAGFLOW_IMAGE=infiniflow/ragflow:v0.25.0
SECRET_KEY=your_secret_key_here
```

### 2.3 修改配置文件

```bash
# 编辑 service_conf.yaml
vi service_conf.yaml

# MySQL配置
mysql:
  name: 'rag_flow'
  user: 'root'
  password: 'ragflow12345678'
  host: 'mysql'
  port: 3306

# Redis配置
redis:
  db: 1
  password: 'ragflow12345678'
  host: 'redis:6379'

# ES配置
es:
  hosts: 'http://es01:9200'
  username: 'elastic'
  password: 'ragflow12345678'
```

### 2.4 启动容器

```bash
# 启动所有服务
docker compose up -d

# 查看容器状态
docker compose ps

# 查看日志
docker compose logs -f ragflow
```

## 三、手动部署（Docker方式）

### 3.1 拉取镜像

```bash
# 从国内镜像拉取
docker pull pgsty/minio
docker pull elasticsearch:8.11.3
docker pull mysql:8.0.39
docker pull valkey/valkey:8

# 导入RAGFlow镜像（如从备份）
docker load -i /mnt/e/桌面/ragflow.tar
```

### 3.2 创建Docker网络

```bash
docker network create ragflow
```

### 3.3 启动容器

```bash
# Redis
docker run -d --name redis --network ragflow \
  -p 6379:6379 \
  valkey/valkey:8 \
  valkey-server --requirepass ragflow12345678

# MySQL
docker run -d --name mysql --network ragflow \
  -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=ragflow12345678 \
  mysql:8.0.39

# Elasticsearch
docker run -d --name es01 --network ragflow \
  -p 9200:9200 \
  -e discovery.type=single-node \
  -e xpack.security.enabled=true \
  -e ELASTIC_PASSWORD=ragflow12345678 \
  elasticsearch:8.11.3

# MinIO
docker run -d --name minio --network ragflow \
  -p 9000:9000 -p 9001:9001 \
  -e MINIO_ROOT_USER=rag_flow \
  -e MINIO_ROOT_PASSWORD=ragflow12345678 \
  pgsty/minio server /data --console-address ":9001"

# RAGFlow
docker run -d --name ragflow --network ragflow \
  -p 80:80 -p 9380:9380 -p 9381:9381 \
  -v /mnt/e/桌面/RAG工单14/uploads:/ragflow/uploads \
  infiniflow/ragflow:v0.25.0
```

### 3.4 初始化数据库

```bash
# 进入ragflow容器
docker exec -it ragflow bash

# 启动ragflow_server
python3 api/ragflow_server.py
```

## 四、配置LLM模型

### 4.1 配置SILICONFLOW

1. 登录RAGFlow Web界面（http://localhost）
2. 进入 设置 → 模型设置
3. 添加SILICONFLOW模型：
   - Factory: SILICONFLOW
   - API Key: `sk-your-api-key`
   - 模型类型：embedding / rerank / chat

### 4.2 配置DeepSeek

1. 添加DeepSeek模型：
   - Factory: DeepSeek
   - API Key: `sk-your-deepseek-key`
   - 模型：deepseek-chat

### 4.3 配置image2txt（可选）

```sql
-- 通过MySQL直接添加
INSERT INTO tenant_llm (

  UNIX_TIMESTAMP(NOW())*1000, NOW(),
  UNIX_TIMESTAMP(NOW())*1000, NOW(),
  '{tenant_id}', 'SILICONFLOW', 'image2text',
  'Qwen/Qwen2.5-VL-7B-Instruct',
```

## 五、知识库创建

### 5.1 通过Web界面创建

1. 登录 http://localhost
2. 点击 知识库 → 创建知识库
3. 填写信息：
   - 名称：RAG工单14
   - 分块方法：naive
   - 分块大小：256
   - 嵌入模型：BAAI/bge-m3@SILICONFLOW

### 5.2 通过API创建

```bash
# 获取API Token
curl -X POST "http://localhost:9380/v1/user/login" \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@test.com","password":"admin123"}'

# 创建知识库
curl -X POST "http://localhost:9380/api/v1/datasets" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "RAG工单14",
    "chunk_method": "naive",
    "parser_config": {"chunk_token_num": 256},
    "embedding_model": "BAAI/bge-m3@SILICONFLOW"
  }'
```

### 5.3 上传PDF文档

```bash
# 上传文档
curl -X POST "http://localhost:9380/api/v1/datasets/{kb_id}/documents" \
  -H "Authorization: Bearer {access_token}" \
  -F "file=@/mnt/e/桌面/工单/RAG工单14/CN100342976C.pdf"

# 触发解析
curl -X POST "http://localhost:9380/api/v1/datasets/{kb_id}/chunks" \
  -H "Authorization: Bearer {access_token}" \
  -H "Content-Type: application/json" \
  -d '{"document_ids":["{doc_id}"],"run":1}'
```

## 七、Chunk内容更新

### 7.1 通过API更新

```python
import requests

BASE = "http://localhost:9380"
TOKEN = "your_api_token"
KB = "knowledge_base_id"
DOC = "document_id"
headers = {"Authorization": "Bearer " + TOKEN, "Content-Type": "application/json"}

# 获取chunks
resp = requests.get(
    BASE + f"/api/v1/datasets/{KB}/documents/{DOC}/chunks",
    headers=headers, params={"page": 1, "page_size": 50}
)
chunks = resp.json()["data"]["chunks"]

# 更新chunk
for c in chunks:
    if "发明人" in c["content"]:
        new_content = c["content"] + "\n\n【发明人】该专利的发明人是P·吉特勒。"
        requests.put(
            BASE + f"/api/v1/datasets/{KB}/documents/{DOC}/chunks/{c['id']}",
            headers=headers, json={"content": new_content}
        )
```

### 7.2 通过MySQL直接更新

```sql
-- 不推荐，可能导致ES不同步
UPDATE chunk SET content = '新内容' WHERE id = 'chunk_id';
```

## 八、故障排查

### 8.1 ragflow_server无法启动

```bash
# 查看日志
docker logs ragflow

# 常见问题
# 1. Redis连接失败：检查密码配置
# 2. MySQL连接失败：检查主机名和端口
# 3. ES索引创建失败：检查ES状态
```

### 8.2 解析任务卡住

```bash
# 查看task_executor日志
docker logs ragflow | grep task_executor

# 重启task_executor
docker exec ragflow pkill -f task_executor.py
```

### 8.3 检索结果为空

```bash
# 检查ES索引
docker exec ragflow curl -s -u elastic:ragflow12345678 \
  "http://es01:9200/_cat/indices?v"

# 检查chunk是否存在
docker exec mysql mysql -u root -pragflow12345678 rag_flow \
  -e "SELECT COUNT(*) FROM chunk WHERE doc_id='xxx';"
```

### 8.4 LLM回答错误

1. 检查检索结果是否正确
2. 检查系统提示词配置
3. 检查LLM模型API Key是否有效

## 九、备份与恢复

### 9.1 备份数据

```bash
# 备份MySQL
docker exec mysql mysqldump -u root -pragflow12345678 rag_flow \
  > /mnt/e/桌面/ragflow_mysql_backup.sql

# 备份ES索引
docker exec es01 curl -X POST "http://localhost:9200/_snapshot/ragflow_backup" \
  -H "Content-Type: application/json" \
  -d '{"location": "/mnt/e/桌面/es_backup"}'

# 备份RAGFlow镜像
docker save infiniflow/ragflow:v0.25.0 \
  > /mnt/e/桌面/ragflow.tar
```

### 9.2 恢复数据

```bash
# 恢复MySQL
docker exec -i mysql mysql -u root -pragflow12345678 rag_flow \
  < /mnt/e/桌面/ragflow_mysql_backup.sql

# 恢复RAGFlow镜像
docker load -i /mnt/e/桌面/ragflow.tar
```
