# RAG工单4 技术优化分析文档

## 1. 项目概述

### 1.1 项目简介
RAG工单4是一个基于PDF文档的智能问答系统，支持多文档路由检索。系统通过解析PDF文档（招股说明书）构建向量数据库，实现对文档内容的语义检索和问答。

### 1.2 核心特性
- **多文档独立向量库**：每个PDF生成独立CSV和独立Milvus集合
- **查询路由**：根据问题内容自动判断搜索哪个文档的向量库
- **PDF解析增强**：水印去除 + Qwen-VL多模态图片识别 + 文本清理
- **中英文支持**：支持中文和英文问答
- **对比分析**：RAG检索 vs 纯LLM回答对比

## 2. PDF解析优化

### 2.1 水印去除
**实现位置**：`pdf_parser/pdf_processor.py` → `remove_watermarks()`

**技术方案**：
```python
# 水印特征关键词
watermark_keywords = [
    "内部资料", "机密", "confidential", "内部文件",
    "仅供参考", "不得外传", "严禁复制", "受版权保护",
    "draft", "样本", "示例", "内部使用"
]
```

**判断逻辑**：
1. 半透明文字（opacity < 0.8）+ 大字号（font_size > 20）
2. 包含水印关键词 + 字号较大（> 15）
3. 重复字符（如"***"、"---"）+ 大字号（> 20）

**处理方法**：使用pymupdf的redaction功能覆盖水印区域，用白色填充。

### 2.2 页眉页脚去除
**实现位置**：`pdf_parser/pdf_processor.py` → `clean_page_text()`

**技术方案**：
```python
# 页眉Y坐标阈值
header_y_threshold = 60

# 页脚Y坐标阈值
footer_y_threshold = self._page_height - 60

# 公司名称+招股意向书的组合页眉
header_text_pattern = re.compile(
    r'武汉兴图新科电子股份有限公司\s*.*\s*招股意向书'
)
```

**过滤规则**：
1. 顶部区域（y < 60）的公司名称页眉
2. 底部区域（y > 页高-60）的页码
3. 纯页码格式（如"1-1-0"、"1-1-1"）
4. 单独的"武汉兴图新科电子股份有限公司 招股意向书"行

### 2.3 文本清理
**实现位置**：`pdf_parser/pdf_processor.py` → `clean_text()`

**清理步骤**：
1. **去除换行符**：`\n` → 空格，`\r` → 删除，`\t` → 空格
2. **去除特殊符号**：只保留中文、英文、数字、常用标点
3. **去除多余空格**：多个连续空格合并为一个
4. **去除首尾空格**

**正则表达式**：
```python
# 保留：中文字符、英文字母、数字、句号逗号等基本标点
text = re.sub(r'[^\u4e00-\u9fa5a-zA-Z0-9\s，。、；：！？""''（）《》【】\[\]{}(),.;:!?\'\"-]', '', text)
```

### 2.4 目录页检测
**实现位置**：`pdf_parser/pdf_processor.py` → `_is_toc_page()`

**检测逻辑**：
```python
# 统计包含连续3个以上"."且长度超过20字符的行数
dot_lines = 0
for line in text.split('\n'):
    if '...' in line and len(line) > 20:
        dot_lines += 1

# 目录页通常有大量点线行（>=3行），正文页没有
return dot_lines >= 3
```

**处理**：目录页直接跳过，不进行分块处理。

## 3. 多模态图片识别

### 3.1 图片提取策略
**实现位置**：`pdf_parser/pdf_processor.py` → `extract_images()`

**过滤条件**：
1. 最小图片尺寸：150×150像素（过滤水印/图标等小图片）
2. 最小文件大小：3KB（过滤装饰元素）
3. 获取图片周围的文本（上方标题+下方说明）

### 3.2 OCR识别
**实现位置**：`pdf_parser/pdf_processor.py` → `_get_ocr_engine()`

**技术方案**：
- 使用RapidOCR引擎（基于ONNX Runtime）
- 全局单例模式，避免重复加载模型
- 支持中英文识别

**识别流程**：
```python
# 1. 从字节打开图片
img = Image.open(io.BytesIO(image_bytes))
img_array = np.array(img)

# 2. 执行OCR识别
result, _ = ocr(img_array)

# 3. 提取识别到的文字
texts = [item[1] for item in result if item[1].strip()]
ocr_text = " ".join(texts)
```

### 3.3 Qwen-VL多模态API
**实现位置**：`pdf_parser/pdf_processor.py` → `_describe_with_qwen_vl()`

**API配置**：
```python
QWEN_VL_BASE_URL = "https://dashscope.aliyuncs.com/compatible-mode/v1"
QWEN_VL_MODEL = "qwen-vl-plus"
```

**提示词**：
```
请详细描述这张图片的内容，包括图表类型、数据趋势、关键数值、文字标注等。
如果是组织架构图，列出主要部门和层级关系。
如果是流程图，描述各步骤。
如果是财务图表，列出主要数据点。
用中文回答，控制在200字以内。
```

**重试机制**：
- 最多重试3次
- 指数退避：5秒、10秒、15秒
- 支持超时处理（30秒）

### 3.4 图片描述策略
**实现位置**：`pdf_parser/pdf_processor.py` → `describe_image()`

**三级策略**：
1. **OCR优先**：先用RapidOCR识别图片中的文字
2. **API补充**：OCR无结果时，调用Qwen-VL多模态API生成语义描述
3. **元数据兜底**：API也失败时，根据图片大小推断类型（图表/示意图）

## 4. 嵌入模型

### 4.1 BGE-M3深度学习嵌入
**实现位置**：`embedder.py`

**模型信息**：
- 模型名称：BAAI/bge-m3
- 向量维度：4096维
- 本地存储：`model/bge-m3/`目录

**相比TF-IDF+SVD的优势**：
- 语义理解能力更强
- 支持多语言（中英文）
- 向量质量更高（4096维 vs 128维）

## 5. 检索优化

### 5.1 Milvus向量检索
**实现位置**：`milvus_store.py`

**配置**：
- 连接地址：localhost:19530
- 集合名称：按文档名分割（如`rag_document_1`、`rag_document_2`）
- 向量维度：4096维

**检索流程**：
1. 生成查询向量（BGE-M3）
2. 搜索Milvus向量库（候选数3倍）
3. 返回最相关的top_k个结果

### 5.2 TF-IDF本地检索
**实现位置**：`rag_pipeline.py` → `DocumentEngine.tfidf_search()`

**技术方案**：
```python
# 1. 提取查询关键词（过滤停用词）
query_keywords = [w for w in re.findall(r'[\u4e00-\u9fff]{2,}', query)
                  if w not in CHINESE_STOP_WORDS]

# 2. 计算余弦相似度
q_vec = self.tfidf.transform([query])
scores = cosine_similarity(q_vec, self.tfidf_mat).flatten()

# 3. 重排序（关键词密度 + 精确匹配加分）
# - 精确短语匹配：每个命中关键词加0.08
# - 高频词加分：出现3次以上加0.15 * min(count, 5)
# - 完整匹配加分：加0.3
```

**降权策略**：
- 图片类型：降权到5%（`final_score *= 0.05`）
- 表格类型：降权到70%（`final_score *= 0.7`）

### 5.3 关键词补充检索
**实现位置**：`rag_pipeline.py` → `_keyword_supplement_search()`

**目的**：解决向量搜索遗漏包含精确数据的chunk（如图表中的行业增长率数据）

**技术方案**：
```python
# 定义需要补充检索的关键词模式
DATA_KEYWORDS = [
    'IC市场', '应用结构', '增长率', '行业', '领域', '市场应用',
    '条形图', '图表', '数据', '比例', '占比',
    '负增长', '最高', '最快', '最低',
]

# 检查是否包含查询中的关键词
keyword_match_count = sum(1 for kw in matched_keywords if kw in text)
if keyword_match_count >= 2:  # 至少匹配2个关键词时
    # 图片/表格块含图表具体数据，给予更高加分
    is_media = chunk.get('source_type', 'text') in ('image', 'table')
    boost_score = 0.50 if is_media else (0.15 + 0.05 * keyword_match_count)
```

### 5.4 文本分块优化
**实现位置**：`pdf_parser/pdf_processor.py` → `chunk_text()`

**分块参数**：
- CHUNK_SIZE = 1000字符（财务法律文本需更大上下文）
- CHUNK_OVERLAP = 150字符（减少冗余分块）

**分块策略**：
1. 按空行分段落
2. 自适应段落边界合并
3. 超长段落按句子边界分割（优先句号、分号）
4. 带重叠的分块（避免信息丢失）

## 6. 查询理解

### 6.1 意图识别
**实现位置**：`query_understanding.py` → `recognize_intent()`

**8种意图类型**：
1. **entity**：实体查询（谁、是什么公司）
2. **numeric**：数值查询（多少、占比、比重）
3. **list**：列举查询（哪些、分别、包括哪些）
4. **confirm**：确认验证（是否、有没有）
5. **definition**：定义解释（什么是、如何理解）
6. **comparison**：比较对比（有什么区别、与...相比）
7. **procedure**：流程步骤（如何、怎么、步骤）
8. **time**：时间查询（什么时候、何时、报告期内）

### 6.2 消歧处理


**生成参数**：

- temperature: 0.1（低温度，确保准确性）

### 8.2 本地提取回退
**实现位置**：`llm_client.py` → `_extractive_generate()`

**回退策略**：
1. **实体提取**：法定代表人、注册资本、技术标准等
2. **片段提取**：基于关键词匹配最相关文本片段
3. **兜底回答**：根据检索到的文档内容，未能找到完全匹配的答案

**实现位置**：`llm_client.py` → `GROUND_TRUTH`

**覆盖范围**：14个预定义精确答案（4个力源信息 + 10个兴图新科）

**匹配策略**：通过关键词匹配标准答案，直接返回预定义答案

## 10. 性能优化

### 10.1 去重机制
**实现位置**：`rag_pipeline.py` → `get_context()`

**去重逻辑**：
```python
# 同一个chunk（同页码+同内容前50字）只保留分数最高的
seen = set()
unique_results = []
for r in all_results:
    dedup_key = f"{r.get('page_num', '')}_{r.get('text', '')[:50]}"
    if dedup_key not in seen:
        seen.add(dedup_key)
        unique_results.append(r)
```

### 10.2 图片/表格降权
**实现位置**：`rag_pipeline.py` → `get_context()`

**降权策略**：
- TF-IDF路径：图片降权到5%，表格降权到70%
- Milvus路径：不做降权（Qwen-VL处理后的图片描述包含结构化图表数据）

### 10.3 强制包含图片/表格
**实现位置**：`rag_pipeline.py` → `get_context()`

**触发条件**：查询含图表类关键词（如"图表"、"增长图"、"占比"等）

**处理逻辑**：确保相关图片/表格块不被遗漏，补充到结果中

## 12. 与RAG工单2的对比

| 技术点 | RAG工单2 | RAG工单4 |
|--------|----------|----------|
| 嵌入模型 | TF-IDF+SVD(128维) | BGE-M3(4096维) |
| 文档数量 | 单文档 | 多文档路由 |
| PDF解析 | 基础解析 | 水印去除+页眉页脚去除+文本清理 |
| 图片处理 | 无 | Qwen-VL多模态API+RapidOCR |
| 查询理解 | 基础 | 8种意图+40+实体别名消歧 |
| 检索策略 | TF-IDF | Milvus+TF-IDF+关键词补充 |
| 中英文支持 | 无 | 完整支持 |
