## 一、系统架构

```
用户浏览器 → FastAPI服务(127.0.0.1:8888)
                ├── bge-m3 嵌入模型 (本地GPU)
                ├── Milvus 向量数据库 (localhost:19530)
                ├── BM25 全文检索 (jieba分词)
                ├── bge-reranker-v2-m3 重排模型 (本地GPU)
                ├── DeepSeek API (api.deepseek.com)
                ├── Redis 缓存 (localhost:6379, 可选)
                └── OpenTelemetry + Prometheus 监控
```

## 四、部署步骤

### 4.1 安装Python依赖

```bash
# 创建conda环境 (推荐)
conda create -n rag python=3.9
conda activate rag

# 安装核心依赖
pip install fastapi uvicorn pydantic
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
pip install sentence-transformers
pip install pymilvus
pip install jieba
pip install requests
pip install redis

# 安装监控依赖
pip install prometheus_client
pip install opentelemetry-api opentelemetry-sdk

# 安装PDF解析依赖
pip install pymupdf
```

### 4.2 配置Milvus

确保Milvus服务已启动:
```bash
# 检查Milvus状态
docker ps | grep milvus

# 如果未启动, 使用Docker启动
docker run -d --name milvus \
  -p 19530:19530 \
  -p 9091:9091 \
  milvusdb/milvus:latest
```

导入数据到Milvus:
```bash
python milvus_init.py
```

### 4.3 配置API密钥

设置DeepSeek API密钥 (二选一):

```bash
# 方式1: 环境变量
set DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxx

# 方式2: 直接修改 llm.py 第16行
DEEPSEEK_API_KEY = 'sk-xxxxxxxxxxxxxxxx'
```

### 4.4 配置Redis (可选)

```bash
# 启动Redis
docker run -d --name redis -p 6379:6379 redis:latest

# 如果Redis未启动, 系统会自动降级使用内存存储
```

## 五、API接口说明

### 5.1 问答接口

**POST /api/ask** — 非流式问答
```json
{
  "question": "武汉兴图新科注册资本是多少?",
  "top_k": 5,
  "lang": "zh",
  "conversation_id": ""
}
```

**POST /api/ask/stream** — 流式问答 (SSE)
```json
{
  "question": "武汉兴图新科注册资本是多少?",
  "top_k": 5,
  "lang": "zh"
}
```

SSE事件格式:
```
data: {"type":"meta", "sources":[...], "retrieve_time":0.34}
data: {"type":"chunk", "content":"武汉"}
data: {"type":"chunk", "content":"兴图新科"}
data: {"type":"done", "total_time":1.58}
```

### 5.2 监控接口

**GET /metrics** — Prometheus指标
**GET /api/traces** — 最近追踪记录
**GET /api/traces/{trace_id}** — 单个追踪详情
**GET /api/alerts** — 告警记录
**GET /api/monitoring/dashboard** — 仪表盘数据

### 5.3 管理接口

**GET /api/files** — 已上传文件列表
**POST /api/upload** — 上传PDF文件
**DELETE /api/files/{filename}** — 删除文件
**POST /api/reload** — 重新加载知识库
**GET /api/health** — 健康检查

## 七、故障排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 启动报错pymilvus | 未安装pymilvus | `pip install pymilvus` |
| Milvus连接失败 | Milvus未启动 | 检查Docker: `docker ps` |
| GPU内存不足 | 模型太大 | 减少top_k或使用CPU模式 |
| DeepSeek API超时 | 网络问题 | 检查网络连通性 |
| Redis连接失败 | Redis未启动 | 系统自动降级为内存存储 |
| jieba加载慢 | 首次加载 | 正常现象, 后续请求无延迟 |

## 九、监控与告警

### Prometheus指标

```
rag_request_total          — 总请求数
rag_request_duration_seconds — 请求延迟分布
rag_stage_duration_seconds   — 各阶段耗时
rag_active_requests         — 并发请求数
rag_alert_total            — 告警总数
```

### 告警阈值

| 类型 | 阈值 | 说明 |
|------|------|------|
| slow_request | 5.0s | 单次请求超过5s |
| slow_retrieval | 1.0s | 检索超过1s |
| slow_llm | 5.0s | LLM生成超过5s |

### 接入Grafana (可选)

1. 安装Prometheus + Grafana
2. 配置Prometheus抓取 http://127.0.0.1:8888/metrics
3. 在Grafana中创建仪表盘, 使用上述指标
