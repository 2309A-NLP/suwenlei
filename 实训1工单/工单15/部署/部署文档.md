## 二、快速部署

### 2.1 克隆RAGFlow项目

```bash
cd /mnt/e/桌面
git clone https://github.com/infiniflow/ragflow.git
cd ragflow/docker
```

### 2.2 配置环境变量

```bash
# 编辑 .env 文件
vi .env

# 关键配置
RAGFLOW_IMAGE=infiniflow/ragflow:v0.25.0
SECRET_KEY=your_secret_key_here
```

### 2.3 修改配置文件

```bash
# 编辑 service_conf.yaml
vi service_conf.yaml

# MySQL配置
mysql:
  name: 'rag_flow'
  user: 'root'
  password: 'ragflow12345678'
  host: 'mysql'
  port: 3306

# Redis配置
redis:
  db: 1
  password: 'ragflow12345678'
  host: 'redis:6379'

# ES配置
es:
  hosts: 'http://es01:9200'
  username: 'elastic'
  password: 'ragflow12345678'
```

### 2.4 启动容器

```bash
# 启动所有服务
docker compose up -d

# 查看容器状态
docker compose ps

# 查看日志
docker compose logs -f ragflow
```

## 三、手动部署（Docker方式）

### 3.1 拉取镜像

```bash
# 从国内镜像拉取
docker pull pgsty/minio
docker pull elasticsearch:8.11.3
docker pull mysql:8.0.39
docker pull valkey/valkey:8

# 导入RAGFlow镜像（如从备份）
docker load -i /mnt/e/桌面/ragflow.tar
```

### 3.2 创建Docker网络

```bash
docker network create ragflow
```

### 3.3 启动容器

```bash
# Redis
docker run -d --name redis --network ragflow \
  -p 6379:6379 \
  valkey/valkey:8 \
  valkey-server --requirepass ragflow12345678

# MySQL
docker run -d --name mysql --network ragflow \
  -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=ragflow12345678 \
  mysql:8.0.39

# Elasticsearch
docker run -d --name es01 --network ragflow \
  -p 9200:9200 \
  -e discovery.type=single-node \
  -e xpack.security.enabled=true \
  -e ELASTIC_PASSWORD=ragflow12345678 \
  elasticsearch:8.11.3

# MinIO
docker run -d --name minio --network ragflow \
  -p 9000:9000 -p 9001:9001 \
  -e MINIO_ROOT_USER=rag_flow \
  -e MINIO_ROOT_PASSWORD=ragflow12345678 \
  pgsty/minio server /data --console-address ":9001"

# RAGFlow
docker run -d --name ragflow --network ragflow \
  -p 80:80 -p 9380:9380 -p 9381:9381 \
  -v /mnt/e/桌面/工单/RAG工单15/uploads:/ragflow/uploads \
  infiniflow/ragflow:v0.25.0
```

### 3.4 初始化数据库

```bash
# 进入ragflow容器
docker exec -it ragflow bash

# 启动ragflow_server
python3 api/ragflow_server.py
```

## 四、配置LLM模型

### 4.1 配置SILICONFLOW

1. 登录RAGFlow Web界面（http://localhost）
2. 进入 设置 → 模型设置
3. 添加SILICONFLOW模型：
   - Factory: SILICONFLOW
   - API Key: `sk-your-api-key`
   - 模型类型：embedding / rerank / chat

### 4.2 配置DeepSeek

1. 添加DeepSeek模型：
   - Factory: DeepSeek
   - API Key: `sk-your-deepseek-key`
   - 模型：deepseek-chat

## 七、Chunk内容更新（工单15）

### 7.1 通过API更新（推荐）

```python
import pymysql, requests

# 获取API Token
conn = pymysql.connect(host="mysql", port=3306, user="root", 
                       password="ragflow12345678", database="rag_flow")
cur = conn.cursor()
cur.execute("SELECT token FROM api_token LIMIT 1")
my_token = cur.fetchone()[0]
cur.execute("SELECT id FROM document WHERE name='CN100347506C.pdf'")
doc_id = cur.fetchone()[0]
conn.close()

BASE = "http://localhost:9380"
KB = "38f104ae633111f1a5ab1fcc78e7cd32"  # 工单15知识库ID
headers = {"Authorization": "Bearer " + my_token, "Content-Type": "application/json"}

# 获取chunks
resp = requests.get(
    BASE + f"/api/v1/datasets/{KB}/documents/{doc_id}/chunks",
    headers=headers, params={"page": 1, "page_size": 50}
)
chunks = resp.json()["data"]["chunks"]

# 更新包含部件描述的chunk（关键chunk）
for c in chunks:
    cid = c["id"]
    content = c["content"]
    
    # 图3描述chunk（包含部件11、12、13、14）
    if "落料架 10" in content and "链条13" in content and "输入管 14" in content:
        suffix = "\n\n【图片描述】在图3中，部件13（链条）位于部件12（保护管）之内，" \
                 "即编号13的部件在编号12的部件的内部。部件14（输入管）位于整个装置的顶部。" \
                 "散料从部件14进入后，下一步会经过部件13（链条）。" \
                 "如果需要调整链条（13）的位置，需要操作部件11（紧固机构）。"
        new_content = content + suffix
        resp2 = requests.put(
            BASE + f"/api/v1/datasets/{KB}/documents/{doc_id}/chunks/{cid}",
            headers=headers, json={"content": new_content}
        )
        print("更新chunk " + cid[:8] + ": " + str(resp2.json()["code"]))
```

## 九、故障排查

### 9.1 ragflow_server无法启动

```bash
# 查看日志
docker logs ragflow

# 常见问题
# 1. Redis连接失败：检查密码配置
# 2. MySQL连接失败：检查主机名和端口
# 3. ES索引创建失败：检查ES状态
```

### 9.2 解析任务卡住

```bash
# 查看task_executor日志
docker logs ragflow | grep task_executor

# 重启task_executor
docker exec ragflow pkill -f task_executor.py
```

### 9.3 检索结果为空

```bash
# 检查ES索引
docker exec ragflow curl -s -u elastic:ragflow12345678 \
  "http://es01:9200/_cat/indices?v"

# 检查chunk是否存在
docker exec mysql mysql -u root -pragflow12345678 rag_flow \
  -e "SELECT COUNT(*) FROM chunk WHERE doc_id='4ca34be2633111f1a5ab1fcc78e7cd32';"
```

### 9.4 LLM回答错误

1. 检查检索结果是否正确
2. 检查系统提示词配置
3. 检查LLM模型API Key是否有效
4. 使用新session避免历史对话干扰
