## 四、运行微调

### 4.1 一键运行（推荐）

```bash
cd RAG工单11
python finetune/run_all.py
```

执行流程：
1. 解析PDF → 生成分块CSV
2. 生成200条训练三元组
3. 微调Embedding模型（2 Epochs）
4. 评估微调前后效果（22项指标）

预计耗时：10-15分钟（含API调用）

### 4.2 分步运行

```bash
# Step 1: 数据准备
python finetune/prepare_data.py

# Step 2: 模型训练
python finetune/train_embedding.py

# Step 3: 评估对比
python finetune/evaluate.py
```

### 4.3 参数配置

如需调整参数，修改对应文件顶部配置：

**`finetune/prepare_data.py`**:
```python
MAX_CHUNKS_FOR_TRAIN = 200  # 生成三元组数量
```

**`finetune/train_embedding.py`**:
```python
BATCH_SIZE = 1              # 批大小
EPOCHS = 2                  # 训练轮数
LEARNING_RATE = 2e-5        # 学习率
WARMUP_STEPS = 20           # 预热步数
```

## 六、常见问题

### 6.1 GPU内存不足

```
错误: CUDA out of memory
```

**解决方案**:
- 减小BATCH_SIZE（改为1）
- 减少语料库大小
- 使用更小的模型

### 6.2 模型下载失败

```
错误: ConnectionError / Timeout
```

**解决方案**:
- 使用镜像站: `HF_ENDPOINT=https://hf-mirror.com`
- 或手动下载模型文件

### 6.3 API调用失败

```
错误: DeepSeek API limit
```

**解决方案**:
- 增加`time.sleep(0.5)`等待时间
- 检查API Key是否有效
