# RAG工单3 技术优化分析文档

## 1. 项目背景

### 1.1 项目定位
RAG工单3是一个**多文档路由检索**的PDF问答系统，相比RAG工单2（单文档检索），核心升级是支持多个PDF文档的独立向量库和智能路由检索。

### 1.2 核心优化点
- **多文档路由**：每个PDF独立向量库，查询自动路由到目标文档
- **PDF解析增强**：水印去除 + Qwen-VL多模态图片识别 + 文本清理
- **嵌入模型升级**：从TF-IDF+SVD升级到BGE-M3深度学习模型
- **查询理解优化**：8种意图识别 + 实体消歧 + 查询扩展

## 2. PDF解析优化

### 2.1 水印去除
```python
# pdf_processor.py - remove_watermarks()
```
**技术实现**：
- 使用pymupdf的redaction功能覆盖水印区域
- 识别三种水印特征：
  1. **半透明文字**：opacity < 0.8 且 font_size > 20
  2. **关键词匹配**：包含"内部资料"、"机密"、"仅供参考"等
  3. **重复字符**：如"***"、"---"等重复模式
- 用白色填充覆盖水印区域

### 2.2 页眉页脚去除
```python
# pdf_processor.py - clean_page_text()
```
**技术实现**：
- 使用pymupdf的blocks定位文本块
- **页眉识别**：Y坐标 < 60px，匹配"武汉兴图新科电子股份有限公司...招股意向书"
- **页脚识别**：Y坐标 > (页高-60px)，纯数字页码
- **页码格式**：正则匹配 `\d+-\d+-\d+` 格式

### 2.3 文本清理
```python
# pdf_processor.py - clean_text()
```
**清理流程**：
1. 去除换行符：`\n` → 空格，`\r` → 删除，`\t` → 空格
2. 去除特殊符号：保留中文、英文、数字、常用标点
3. 合并多余空格：多个连续空格 → 单个空格
4. 去除首尾空格

### 2.4 目录页检测
```python
# pdf_processor.py - _is_toc_page()
```
**检测逻辑**：
- 统计包含连续3个以上"..."且长度>20字符的行数
- 目录页特征：点线行数 >= 3
- 自动跳过目录页不处理

## 4. 嵌入模型优化

### 4.1 从TF-IDF到BGE-M3
```python
# embedder.py
```
**升级对比**：
| 特性 | TF-IDF+SVD | BGE-M3 |
|------|------------|--------|
| 维度 | 128维 | 4096维 |
| 语义理解 | 弱（词频统计） | 强（深度学习） |
| 多语言 | 不支持 | 支持100+语言 |
| 稀疏检索 | 不支持 | 支持（BM25融合） |
| 密集检索 | 支持 | 支持 |

### 4.2 BGE-M3模型
```python
# embedder.py - get_embedding_model()
```
**技术特点**：
- 模型：`BAAI/bge-m3`（北京智源研究院）
- 维度：4096维
- 本地加载：`model/bge-m3/` 目录
- 归一化：`normalize_embeddings=True`

### 4.3 嵌入生成
```python
def embed_texts(texts: list) -> list:
    """批量文本嵌入"""
    model = get_embedding_model()
    embeddings = model.encode(texts, normalize_embeddings=True)
    return embeddings.tolist()

def embed_query(query: str) -> list:
    """查询嵌入"""
    model = get_embedding_model()
    embedding = model.encode([query], normalize_embeddings=True)
    return embedding[0].tolist()
```

## 6. 查询理解优化

### 6.1 意图识别
```python
# query_understanding.py - recognize_intent()
```
**8种意图类型**：
1. **entity**：实体查询（谁、是什么公司）
2. **numeric**：数值查询（多少、占比、比重）
3. **list**：列举查询（哪些、分别）
4. **confirm**：确认验证（是否、有没有）
5. **definition**：定义解释（什么是、什么叫）
6. **comparison**：比较对比（有什么区别、对比）
7. **procedure**：流程步骤（如何、怎么）
8. **time**：时间查询（什么时候、报告期内）

### 6.2 实体消歧
```python
# query_understanding.py - disambiguate()
```
**消歧策略**：
- 按别名长度降序匹配（长词优先）
- 检查替换位置重叠（防止重复替换）
- 检查文本已包含完整替换（防止重复）

**实体别名映射**（40+条）：

_ENTITY_ALIASES = {

## 7. 检索优化

### 7.1 混合检索策略
```python
# rag_pipeline.py - get_context()
```
**检索流程**：
1. 路由判断目标文档
2. 优先Milvus向量检索
3. 降级到TF-IDF本地检索
4. 关键词补充检索
5. 去重排序取top_k

### 7.2 关键词补充检索
```python
# rag_pipeline.py - _keyword_supplement_search()
```
**解决问题**：向量搜索可能遗漏包含精确数据的chunk（如图表数据）

**关键词模式**：
```python
DATA_KEYWORDS = [
    'IC市场', '应用结构', '增长率', '行业', '领域',
    '条形图', '图表', '数据', '比例', '占比',
    '负增长', '最高', '最快', '最低',
]
```

### 7.3 TF-IDF重排序
```python
# rag_pipeline.py - DocumentEngine.tfidf_search()
```
**重排序策略**：
1. **关键词密度加分**：每个命中关键词 +0.08
2. **高频词额外加分**：出现3次以上 +0.15*次数
3. **完整匹配大幅加分**：完整查询在文本中 +0.3
4. **图片降权**：image类型 * 0.05
5. **表格降权**：table类型 * 0.7

## 8. 文本分块优化

### 8.1 分块参数
```python
CHUNK_SIZE = 1000  # 从800增至1000（财务法律文本需更大上下文）
CHUNK_OVERLAP = 150  # 从200减至150（减少冗余分块）
```

### 8.2 自适应分块策略
```python
# pdf_processor.py - chunk_text()
```
**分块逻辑**：
1. 按空行分段落
2. 合并小段落（不超过CHUNK_SIZE）
3. 分割大段落（按句子边界分割）
4. 带重叠（CHUNK_OVERLAP）

### 8.3 分块类型
- **text**：正文文本分块
- **table**：表格转文本分块（带"[表格]"标记）
- **image**：图片语义描述分块（带"[图片]"标记）
