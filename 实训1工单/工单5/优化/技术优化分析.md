# RAG工单5 技术优化分析文档

## 1. 项目概述

### 1.1 项目简介
RAG工单5是一个基于PDF文档的智能问答系统，支持多文档路由检索和多轮对话记忆。系统通过解析PDF文档（招股说明书）构建向量数据库，实现对文档内容的语义检索和问答。

### 1.2 核心特性
- **多文档独立向量库**：每个PDF生成独立CSV和独立Milvus集合
- **查询路由**：根据问题内容自动判断搜索哪个文档的向量库
- **多轮对话记忆**：支持上下文理解，支持指代消解
- **中英文支持**：支持中文和英文问答
- **对比分析**：RAG检索 vs 纯LLM回答对比

## 2. 核心新增功能：多轮对话记忆

### 2.1 Redis对话存储
**实现位置**：`redis_store.py` → `ConversationStore`

**核心设计**：
```python
class ConversationStore:
    """对话历史存储：Redis优先，自动降级内存"""
    def __init__(self, host='127.0.0.1', port=6379, db=0, password=None, ttl_hours=24):
        self.ttl = timedelta(hours=ttl_hours)  # 对话过期时间：默认24小时
        self.prefix = 'rag:conv:'  # Redis key前缀，隔离业务数据
```

**存储结构**：
- Key格式：`rag:conv:{conversation_id}`
- Value：JSON格式的消息列表
- TTL：24小时自动过期

**降级策略**：
- Redis可用：使用Redis持久化存储
- Redis不可用：自动降级为内存字典（进程重启丢失）

### 2.4 Prompt构建增强
**实现位置**：`rag_pipeline.py` → `build_prompt()`

**技术方案**：
```python
def build_prompt(self, question: str, context: str, history: list = None, lang: str = 'zh'):
    # 拼接最近3轮对话历史（6条消息），帮助LLM理解"这个公司"等指代
    history_block = ""
    if history and len(history) > 0:
        recent = history[-6:]
        lines = []
        for msg in recent:
            role = "用户" if msg["role"] == "user" else "助手"
            lines.append(f"{role}：{msg['content'][:150]}")
        history_block = "最近的对话历史：\n" + "\n".join(lines) + "\n\n"
```

## 3. PDF解析优化

### 3.1 水印去除
**实现位置**：`pdf_parser/pdf_processor.py` → `remove_watermarks()`

**技术方案**：
```python
# 水印特征关键词
watermark_keywords = [
    "内部资料", "机密", "confidential", "内部文件",
    "仅供参考", "不得外传", "严禁复制", "受版权保护",
    "draft", "样本", "示例", "内部使用"
]
```

**判断逻辑**：
1. 半透明文字（opacity < 0.8）+ 大字号（font_size > 20）
2. 包含水印关键词 + 字号较大（> 15）
3. 重复字符（如"***"、"---"）+ 大字号（> 20）

**处理方法**：使用pymupdf的redaction功能覆盖水印区域，用白色填充。

### 3.2 页眉页脚去除
**实现位置**：`pdf_parser/pdf_processor.py` → `clean_page_text()`

**过滤规则**：
1. 顶部区域（y < 60）的公司名称页眉
2. 底部区域（y > 页高-60）的页码
3. 纯页码格式（如"1-1-0"、"1-1-1"）
4. 单独的"武汉兴图新科电子股份有限公司 招股意向书"行

### 3.3 文本清理
**实现位置**：`pdf_parser/pdf_processor.py` → `clean_text()`

**清理步骤**：
1. **去除换行符**：`\n` → 空格，`\r` → 删除，`\t` → 空格
2. **去除特殊符号**：只保留中文、英文、数字、常用标点
3. **去除多余空格**：多个连续空格合并为一个
4. **去除首尾空格**

### 3.4 目录页检测
**实现位置**：`pdf_parser/pdf_processor.py` → `_is_toc_page()`

**检测逻辑**：
```python
# 统计包含连续3个以上"."且长度超过20字符的行数
dot_lines = 0
for line in text.split('\n'):
    if '...' in line and len(line) > 20:
        dot_lines += 1

# 目录页通常有大量点线行（>=3行），正文页没有
return dot_lines >= 3
```

**单例模式**：
```python
class MilvusStore:
    """Milvus向量存储（单例模式）：无pymilvus时自动降级"""
    _instance = None
    
    def __new__(cls, *args, **kwargs):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance
```

### 6.2 TF-IDF本地检索
**实现位置**：`rag_pipeline.py` → `DocumentEngine.tfidf_search()`

**技术方案**：
```python
# 1. 提取查询关键词（过滤停用词）
query_keywords = [w for w in re.findall(r'[\u4e00-\u9fff]{2,}', query)
                  if w not in CHINESE_STOP_WORDS]

# 2. 计算余弦相似度
q_vec = self.tfidf.transform([query])
scores = cosine_similarity(q_vec, self.tfidf_mat).flatten()

# 3. 重排序（关键词密度 + 精确匹配加分）
# - 精确短语匹配：每个命中关键词加0.08
# - 高频词加分：出现3次以上加0.15 * min(count, 5)
# - 完整匹配加分：加0.3
```

## 7. 查询理解

### 7.1 意图识别
**实现位置**：`query_understanding.py` → `recognize_intent()`

**8种意图类型**：
1. **entity**：实体查询（谁、是什么公司）
2. **numeric**：数值查询（多少、占比、比重）
3. **list**：列举查询（哪些、分别、包括哪些）
4. **confirm**：确认验证（是否、有没有）
5. **definition**：定义解释（什么是、如何理解）
6. **comparison**：比较对比（有什么区别、与...相比）
7. **procedure**：流程步骤（如何、怎么、步骤）
8. **time**：时间查询（什么时候、何时、报告期内）
