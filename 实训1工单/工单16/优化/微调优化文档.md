# RAG工单16 - Qwen2-VL-2B视觉语言模型微调优化文档

## 1. 项目概述

**目标**: 对Qwen2-VL-2B-Instruct进行LoRA微调，提升工业术语和图纸理解能力
**评估集**: 201条（Group 1文本理解67 + Group 2图纸推理67 + Group 3复杂图纸推理67）
**训练集**: 3364条（三组各1/3抽样）
**平台**: autoDL RTX 4080 32GB + LLaMA-Factory 0.9.5

## 2. 训练配置

### v1 首次微调

| 参数 | 值 |
|------|-----|
| LoRA rank | 8 |
| LoRA alpha | 16 |
| 训练轮数 | 2 |
| 学习率 | 2e-4 |
| Warmup | 0.1 |
| Batch size | 4 × 4 = 16 |
| 总步数 | 420 |
| 训练时间 | 20分54秒 |

### v2 优化微调

| 参数 | 值 |
|------|-----|
| LoRA rank | 16 |
| LoRA alpha | 32 |
| 训练轮数 | 3 |
| 学习率 | 1e-4 |
| Warmup | 0.15 |
| Batch size | 4 × 4 = 16 |
| 总步数 | 630 |
| 训练时间 | 约30分钟 |

### 优化调整说明

| 调整项 | v1→v2 | 原因 |
|--------|-------|------|
| LoRA rank | 8→16 | 增加模型容量，提升对复杂图纸的理解能力 |
| LoRA alpha | 16→32 | 与rank保持2:1比例，增强LoRA微调效果 |
| Epochs | 2→3 | 增加训练轮数，充分拟合数据 |
| Learning rate | 2e-4→1e-4 | 降低学习率，避免过拟合，训练更稳定 |
| Warmup | 0.1→0.15 | 增加预热比例，初期训练更平滑 |

## 4. 失败案例分析

### 典型错误类型

| 错误类型 | 数量 | 占比 | 示例 |
|----------|------|------|------|
| 部件位置关系判断 | 8 | 40% | 部件9相对于部件7的位置关系 |
| 流程/路径推理 | 5 | 25% | 空气经过干燥装置后经过哪个部件 |
| 操作影响判断 | 4 | 20% | 螺杆顺时针转动后支撑架位置变化 |
| 功能识别 | 3 | 15% | 编号为7的部件是什么 |

### 难点总结

1. **位置关系题**: 模型容易混淆上下左右方位，特别是斜向关系
2. **流程推理题**: 需要理解多个部件的连接顺序，当前仍有一定失败率
3. **电路图题**: 电路逻辑推理超出VLM视觉理解能力，更适合纯文本模型

## 5. 环境部署经验

### autoDL平台

| 项目 | 说明 |
|------|------|
| GPU | RTX 4080 32GB |
| 系统盘 | 30GB（易满，需定期清理） |
| 数据盘 | 50GB（存放模型、数据） |
| conda环境 | llama（Python 3.11） |
| LLaMA-Factory | 0.9.5（从0.9.1升级） |

### 踩坑记录

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 训练静默退出无报错 | YAML缺少`do_train: true` | 添加配置项 |
| `image_max_pixels`报错 | LLaMA-Factory 0.9.1不支持 | 升级到0.9.5或删除该参数 |
| bitsandbytes加载失败 | 缺少libnvJitLink.so.13 | 卸载bitsandbytes（评估不需要量化） |
| 系统盘满（30GB） | internlm2模型占15GB | `rm -rf /root/internlm2_5-7b-chat` |
| torchvision装不上 | torch 532MB下载超时 | 清理空间后重装 |
| GitHub/pip源被墙 | autoDL国内网络 | 用aliyun镜像源 |
| 图片路径错误 | imdr_vlm.json中用WSL路径 | sed替换为autoDL路径 |

### 训练启动命令

```bash
# 环境准备
source /root/miniconda3/etc/profile.d/conda.sh && conda activate llama

# 训练（v2配置）
cd /root/LLaMA-Factory
llamafactory-cli train /root/RAG工单16/qwen2vl_lora_sft_v2.yaml

# 评估
cd /root/RAG工单16
python eval_finetuned.py
python generate_report.py
```

## 6. 后续优化方向

### 短期（可立即实施）

1. **提高图片分辨率**: 当前512×512，可提升到768×768保留更多图纸细节
2. **增加训练数据**: 当前3364条，可扩增到5000-8000条
3. **数据清洗**: 剔除答案有歧义的样本，人工校验训练数据质量

### 中期（需要更多资源）

4. **更大模型**: 尝试Qwen2-VL-7B-Instruct（需80GB+显存）
5. **更多epoch**: 尝试4-5轮训练观察是否过拟合
6. **混合精度训练**: 尝试fp16替代bf16

### 长期（架构优化）

7. **多模态RAG**: 将VLM微调与RAG检索结合，提升工业文档问答
8. **领域预训练**: 在工业专利语料上继续预训练
9. **知识蒸馏**: 用大模型（72B）蒸馏到小模型（2B）
