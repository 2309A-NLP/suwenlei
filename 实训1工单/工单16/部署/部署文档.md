## 2. 环境搭建

### 2.1 创建conda环境

```bash
# 如果已有llama环境可跳过
conda create -n llama python=3.11 -y
conda activate llama
```

### 2.2 安装LLaMA-Factory

```bash
# 从PyPI安装（国内镜像）
pip install llamafactory -i https://mirrors.aliyun.com/pypi/simple

# 如果版本不对，手动指定
pip download llamafactory --no-deps -d /tmp/llama_pkg -i https://mirrors.aliyun.com/pypi/simple
pip install --no-deps --force-reinstall /tmp/llama_pkg/llamafactory-0.9.5-py3-none-any.whl
```

### 2.3 安装依赖

```bash
pip install torch torchvision -i https://mirrors.aliyun.com/pypi/simple
pip install peft qwen-vl-utils -i https://mirrors.aliyun.com/pypi/simple
```

### 2.4 下载模型

```bash
pip install modelscope -i https://mirrors.aliyun.com/pypi/simple

python -c "

```

## 4. 模型微调

### 4.1 训练配置

配置文件: `qwen2vl_lora_sft.yaml`

```yaml
model_name_or_path: /root/autodl-tmp/models/Qwen/Qwen2-VL-2B-Instruct
finetuning_type: lora
lora_target: all
lora_rank: 16
lora_alpha: 32
lora_dropout: 0.05
dataset_dir: /root/LLaMA-Factory/data
dataset: imdr_vlm
template: qwen2_vl
cutoff_len: 2048
output_dir: /root/RAG工单16/output_v2
per_device_train_batch_size: 4
gradient_accumulation_steps: 4
num_train_epochs: 3
learning_rate: 1.0e-4
lr_scheduler_type: cosine
warmup_ratio: 0.15
bf16: true
gradient_checkpointing: true
max_grad_norm: 1.0
logging_steps: 10
save_steps: 500
save_total_limit: 2
seed: 42
report_to: none
do_train: true
```

### 4.2 启动训练

```bash
source /root/miniconda3/etc/profile.d/conda.sh && conda activate llama
cd /root/LLaMA-Factory
llamafactory-cli train /root/RAG工单16/qwen2vl_lora_sft_v2.yaml 2>&1 | tee /root/RAG工单16/train_v2.log
```

### 4.3 训练监控

## 7. 常见问题

### Q1: 训练静默退出无报错
**原因**: YAML缺少`do_train: true`
**解决**: 在yaml末尾添加 `do_train: true`

### Q2: `image_max_pixels`参数报错
**原因**: LLaMA-Factory 0.9.1不支持
**解决**: 升级到0.9.5，或删除yaml中`image_max_pixels`和`image_min_pixels`两行

### Q3: bitsandbytes加载失败
**原因**: 缺少CUDA库libnvJitLink.so.13
**解决**: 评估时卸载bitsandbytes（`pip uninstall bitsandbytes -y`）

### Q4: 系统盘空间不足
**原因**: 模型和缓存占用过大
**解决**:
```bash
rm -rf /root/internlm2_5-7b-chat          # 释放15GB
rm -rf /root/LLaMA-Factory/.git           # 释放200MB
rm -rf /tmp/pip-unpack-*                  # 释放1.6GB
conda clean --all -y                      # 释放500MB
```

### Q5: torchvision安装超时
**原因**: torch包532MB下载慢
**解决**: 清理空间后重新安装，或用conda安装

### Q6: GitHub/pip源被墙
**原因**: autoDL国内网络
**解决**: 使用aliyun镜像源 `-i https://mirrors.aliyun.com/pypi/simple`

### Q7: 图片路径找不到
**原因**: imdr_vlm.json中的路径是WSL路径
**解决**: `sed -i 's|/mnt/e/桌面/工单/RAG工单16/page_images|/root/RAG工单16/page_images|g' /root/LLaMA-Factory/data/imdr_vlm.json`
