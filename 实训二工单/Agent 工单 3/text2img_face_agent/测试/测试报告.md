## 四、已知差异与改进项

1. **三视图背景灰度未完全统一**：`qwen-image-edit` 每次生成的影室背景灰度有轻微差异
   （端正偏亮、左右偏冷）。每张图**内部**背景一致、符合"扩图与原图一致"；
   但三张并排时灰度不完全统一。可选改进：本地后处理把三图背景归一到同一目标灰度。
2. **侧脸 yaw 精确角度**：Haar 级联只能粗判朝向差异，未给出精确角度数值；
   当前以"三视图朝向有显著差异 + 目测 ±30°"作为验收依据。

## 五、结论

- **功能层面**：✅ 完全满足——输入一张人脸，自动产出左转/端正/右转三视图 + 扩图 + 对比拼图。
- **效果层面**：✅ 面部特征保持、角度变化、清晰度、扩图连贯性均达标；
  仅"三视图间背景灰度统一"为锦上添花项，不影响单图验收。
- **Agent 能力**：✅ LLM 自主编排与确定性流水线两种模式均端到端跑通。
