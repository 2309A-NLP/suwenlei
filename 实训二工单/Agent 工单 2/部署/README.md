# 日程提醒智能体

> 工单编号：人工智能NLP-Agent数字人项目-日程提醒智能体任务

一个基于自然语言对话的日程提醒智能体：支持日程的 **增 / 删 / 改 / 查**、**循环日程**，
并在日程到点时主动发出 **温馨提醒**。所有日程数据保存在本地 **SQLite 数据库**。
**纯 Python 标准库实现，无需安装任何第三方依赖。**

---

## 一、运行环境

- Python 3.8+
- 无需第三方库（仅用 `sqlite3 / threading / datetime / re`）

## 二、快速开始

```bash
# 进入项目目录
cd 日程提醒智能体

# 启动对话（同时启动后台提醒）
python main.py

# 运行验收测试
python test_agent.py
```

> Windows 命令行若中文/符号显示异常，可先执行 `chcp 65001` 切换到 UTF-8，
> 或设置环境变量 `set PYTHONUTF8=1` 后再运行。

## 三、使用示例

```
您：添加日程：下午 5 点开会
智能体：已为您记录日程（编号 1）：
        时间：17:00    一次性
        事项：开会
        标准格式：17:00|0000000|开会

您：每周一和周五早上 8 点提醒我开晨会
智能体：已为您记录日程（编号 2）：
        时间：08:00    每周一、周五 循环
        事项：开晨会
        标准格式：08:00|1000100|开晨会

您：15:15|0000001|提醒我买咖啡       ← 也支持直接输入标准格式
智能体：已为您记录日程（编号 3）：每周日循环

您：我今天的日程有哪些？
智能体：您今天的日程包括：
        1. 17:00 开会

您：删除日程 1
智能体：您确定要删除日程 1 吗？内容是：17:00 开会。回复「确认」执行删除。
您：确认
智能体：已经删除日程 1，删除的日程内容是：17:00 开会
```

到点时智能体会主动推送（4 种话术轮换）：

```
[提醒] 温馨提醒：买咖啡的时间到啦，主人！
```

## 四、循环规则说明

循环规则为 7 位字符串 `YYYYYYY`，依次对应 **周一~周日**，`1` 循环、`0` 不循环：

| 输入 | 规则 | 含义 |
| --- | --- | --- |
| 每天 | `1111111` | 每天 |
| 工作日 | `1111100` | 周一~周五 |
| 周末 | `0000011` | 周六、周日 |
| 每周一和周五 | `1000100` | 周一、周五 |
| 每周日 | `0000001` | 周日 |
| （不指定） | `0000000` | 一次性，仅当天 |
