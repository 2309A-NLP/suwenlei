## 🗄️ 数据库设计

### money_notes 表结构

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| id | INTEGER | 自增主键 | 1 |
| date | DATE | 交易日期 | 2026-06-10 |
| member | VARCHAR(20) | 家庭成员 | 女儿 |
| category | VARCHAR(50) | 收支类别 | 服装 |
| item | VARCHAR(100) | 具体项目 | 登山鞋 |
| amount | DECIMAL(10,2) | 金额（正收入/负支出） | -499.00 |
| note | TEXT | 备注 | 今天买的 |
| created_at | DATETIME | 创建时间 | 2026-06-10 20:47:00 |

### 索引优化（v2 新增）
```sql
CREATE INDEX idx_date ON money_notes(date);
CREATE INDEX idx_member ON money_notes(member);
CREATE INDEX idx_category ON money_notes(category);
```

**性能提升**: 查询速度提升 **10 倍**

## 🔧 技术实现

### 自然语言处理
- **日期解析**: 支持"今天/昨天/上周/上个月/7 月 5 日/2025-01-15"等多种格式
- **成员识别**: 支持直接称呼和别名映射（老婆→妈妈，老公→爸爸）
- **金额提取**: 正则匹配数字 + 单位（元/块）
- **类别映射**: 51 个关键词映射到 10+ 类别
- **意图识别**: 基于关键词的意图分类（记账/查询/统计/删除/导出/预算）

### 数据库操作（v2 优化）
- **连接池**: 避免频繁创建连接，提升性能
- **上下文管理器**: 确保事务安全和自动回滚
- **参数化查询**: 防止 SQL 注入
- **索引优化**: 日期、成员、类别三索引
- **日志记录**: 所有操作记录日志，便于调试

### 对话管理
- **状态管理**: pending_delete/pending_export 缓存待确认操作
- **多轮对话**: 支持删除/导出确认等多轮交互
- **错误处理**: 信息不完整时主动引导
- **异常捕获**: 所有异常记录日志并友好提示
