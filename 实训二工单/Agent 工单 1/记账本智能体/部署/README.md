# 家庭记账本智能体 - 使用说明

## 🚀 快速开始

### 1. 环境要求
- Python 3.8+
- SQLite 3（Python 内置）
- 依赖包：Flask, flask-cors（Web 模式需要）

### 2. 安装依赖

```bash
cd /mnt/e/桌面/工单/Agent 工单 1/记账本智能体

```

### 3. 运行方式

#### 方式 1: 命令行交互



## 🗄️ 数据库说明

### 表结构
- **表名**: money_notes
- **字段**:
  - id: 自增主键
  - date: 交易日期
  - member: 家庭成员（爸爸/妈妈/女儿）
  - category: 收支类别
  - item: 具体项目
  - amount: 金额（正为收入，负为支出）
  - note: 备注
  - created_at: 创建时间

### 数据库位置
```
/mnt/e/桌面/工单/Agent 工单 1/记账本智能体/money_notes.db
```

### 索引优化
- `idx_date`: 加速日期查询
- `idx_member`: 加速成员查询
- `idx_category`: 加速类别查询

## ❓ 常见问题

### Q1: 金额解析错误？
**A**: 确保金额后带"元"或"块"单位，如"499 元"

### Q2: 成员识别失败？
**A**: 使用标准称呼（爸爸/妈妈/女儿）或常见别名（老婆/老公/孩子）

### Q3: 删除操作无法执行？
**A**: 删除需要两步：
1. 说"删除 XXX 的费用"查看预览
2. 回复"确认删除"执行操作

### Q4: 数据库文件在哪？
**A**: 在项目根目录的 `money_notes.db` 文件

### Q5: 如何导出 Excel？
**A**: 当前支持 CSV 格式，可用 Excel 打开。如需 Excel 原生格式，安装 pandas 后修改 `export_to_csv` 函数。

### Q6: Web 界面打不开？
**A**: 
1. 检查 Flask 是否安装：`pip install flask flask-cors`
2. 检查端口是否被占用：`netstat -ano | findstr 5000`
3. 查看日志文件：`app.log`
