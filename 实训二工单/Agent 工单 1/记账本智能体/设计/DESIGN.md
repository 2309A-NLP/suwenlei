## 1. 功能模块

### 1.1 核心功能
1. **记账功能**: 通过自然语言对话记录家庭收支
2. **查询功能**: 按时间、成员、类别等多维度查询
3. **删除功能**: 删除指定记录（需确认）
4. **统计功能**: 汇总统计（月度、成员、类别）

### 1.2 家庭成员
- 爸爸
- 妈妈
- 女儿

## 2. 流程图

```
用户输入 → 意图识别 → 提取实体 → 执行操作 → 返回结果
    ↓           ↓          ↓          ↓          ↓
 自然语言   记账/查询/删除  日期/成员/金额  数据库操作  格式化回复
```

### 2.1 记账流程
```
用户输入 → 识别为记账意图 → 提取 (日期，成员，类别，项目，金额) 
    → 信息不完整则引导补充 → 调用 database_tool 存储 → 确认回复
```

### 2.2 查询流程
```
用户输入 → 识别为查询意图 → 提取查询条件 → 调用 database_tool 查询 
    → 格式化结果 → 返回给用户
```

### 2.3 删除流程
```
用户输入 → 识别为删除意图 → 提取删除条件 → 查询匹配记录 
    → 显示待删除记录 → 请求确认 → 确认后执行删除 → 确认回复
```

## 3. 数据库设计

### 3.1 表名：money_notes

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| id | INTEGER PRIMARY KEY | 自增 ID | 1 |
| date | DATE | 交易日期 | 2025-01-15 |
| member | VARCHAR(20) | 家庭成员 | 爸爸/妈妈/女儿 |
| category | VARCHAR(50) | 收支类别 | 买书/餐饮/交通/收入等 |
| item | VARCHAR(100) | 具体项目 | 三体/登山鞋/旅游团 |
| amount | DECIMAL(10,2) | 金额 (正为收入，负为支出) | -50.00 |
| note | TEXT | 备注信息 | 今天买的 |
| created_at | DATETIME | 创建时间 | 2025-01-15 10:30:00 |

### 3.2 SQL 建表语句
```sql
CREATE TABLE IF NOT EXISTS money_notes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    date DATE NOT NULL,
    member VARCHAR(20) NOT NULL,
    category VARCHAR(50) NOT NULL,
    item VARCHAR(100),
    amount DECIMAL(10,2) NOT NULL,
    note TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## 4. 系统提示词设计

### 4.1 角色设定
你是一个家庭记账本智能体，专门帮助家庭记录和管理日常收支。

### 4.2 核心能力
1. **信息提取**: 从用户自然语言中提取日期、成员、类别、项目、金额
2. **数据库调用**: 必须调用 money_notes 表进行增删查改
3. **完整性引导**: 当用户输入信息不完整时，主动引导补充
4. **确认机制**: 删除操作前必须显示待删除记录并请求确认

### 4.3 输出格式
- 记账成功：确认记录已保存，显示关键信息
- 查询结果：清晰列出匹配的记录或汇总统计
- 删除确认：显示待删除记录，等待用户确认
